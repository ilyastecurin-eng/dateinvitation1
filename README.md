# ♥ Приглашение на свидание

Интерактивный сайт-приглашение: вступление → вопрос «Ты хочешь пойти со мной на свидание?» → выбор дня в октябре 2026 → выбор времени → подтверждение.

React + Vite, без сервера. Публикуется на GitHub Pages автоматически.

---

## Что должно лежать в репозитории

Ровно такая структура — в **корне** репозитория (не внутри ещё одной папки):

```
.github/
  workflows/
    deploy.yml          ← автопубликация
src/
  App.jsx
  BookingConfirmation.jsx
  Calendar.jsx
  CuteAnimation.jsx
  DateQuestion.jsx
  DeclinedScreen.jsx
  IntroScreen.jsx
  ScheduleScreen.jsx
  TimePicker.jsx
  booking.js
  content.js            ← ВСЕ ТЕКСТЫ САЙТА
  date.js
  main.jsx
  styles.css            ← цвета и оформление
.gitignore
README.md
index.html
package.json
vite.config.js          ← именно с точкой, не vite_config.js
```

## Публикация на GitHub Pages — пошагово

### 1. Создайте репозиторий

1. [github.com](https://github.com) → **+** справа вверху → **New repository**.
2. Имя: `dateinvitation1` (подойдёт любое — путь сайта подстраивается сам).
3. Видимость: **Public**.
4. Никаких галочек (README, .gitignore, license) **не ставьте**.
5. **Create repository**.

### 2. Загрузите файлы

1. Распакуйте архив. Откройте папку `dateinvitation1` в Проводнике — внутри видны `.github`, `src`, `index.html` и т. д.
2. На странице репозитория нажмите ссылку **uploading an existing file**.
3. В Проводнике выделите **всё содержимое** папки (`Ctrl + A`) и **перетащите мышкой** в окно браузера.
   ⚠️ Не используйте кнопку «choose your files» — через неё папки не загружаются.
4. Дождитесь, пока в списке появятся все файлы (включая `src/...` и `.github/workflows/deploy.yml`).
5. Внизу **Commit changes**.

Проверьте: на главной странице репозитория должны быть видны папки `.github` и `src`.

**Если папки `.github` нет** (иногда браузер её пропускает) — создайте файл вручную:
**Add file → Create new file** → в поле имени введите `.github/workflows/deploy.yml` (слэши сами создадут папки) → вставьте содержимое файла `deploy.yml` из архива (откройте его Блокнотом) → **Commit changes**.

### 3. Включите GitHub Pages

1. В репозитории: **Settings → Pages**.
2. **Build and deployment → Source**: выберите **GitHub Actions**.

### 4. Запустите публикацию

1. Вкладка **Actions** → слева **Deploy to GitHub Pages**.
2. Если запуск уже есть и он красный (он мог упасть до шага 3) — откройте его и нажмите **Re-run all jobs**.
   Если запуска нет — справа **Run workflow** → **Run workflow**.
3. Через 1–2 минуты появится зелёная галочка.

### 5. Ссылка на сайт

```
https://ВАШ_ЛОГИН.github.io/dateinvitation1/
```

Она же показана в **Settings → Pages** и в зелёном запуске на вкладке **Actions** (под блоком deploy).

### Если сборка упала

Откройте красный запуск → слева **build** → разверните шаг с крестиком. Шаг **Check project files** напишет, какого файла не хватает, и покажет список всего, что лежит в репозитории.

## Как менять тексты и оформление

- **Тексты**: `src/content.js`. На GitHub: откройте файл → карандаш ✏️ → поправьте → **Commit changes**. Сайт обновится сам через 1–2 минуты.
- **Цвета**: блок `:root` в начале `src/styles.css`.
- **Фразы после «Нет»**: массив `noReactions` в `src/content.js`. Когда фразы закончатся, следующее «Нет» засчитывается честно — появляется экран «Хорошо, я понял».

## Сохранение выбора

После нажатия «Готово» выбор сохраняется в **localStorage** браузера:

```json
{ "date": "2026-10-15", "time": "19:00" }
```

При повторном открытии сайт сразу показывает подтверждение.

> ⚠️ localStorage хранит выбор **только в браузере того, кто выбирал**. Вы у себя его не увидите — попросите скриншот или файл из кнопки «Добавить в календарь». Чтобы выбор приходил вам или время становилось занятым для других, нужен backend / база данных.

Всё сохранение идёт через функции `saveBooking()` / `getBooking()` / `clearBooking()` в `src/booking.js`. Чтобы подключить базу данных, достаточно написать новый адаптер (пример есть в файле в комментарии) и заменить строку `const adapter = localStorageAdapter;` — остальной код менять не нужно.

Чтобы пройти сайт заново «с нуля» — откройте его в режиме инкогнито.

## Локальный запуск (необязательно)

Нужен [Node.js](https://nodejs.org) 18+.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # готовый сайт в папке dist/
```
